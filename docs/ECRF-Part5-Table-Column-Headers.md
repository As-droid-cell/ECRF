# ECRF · Part 5 — Table Column Headers (Reference)

This file reproduces Part Three from the Foundations text: the table column headers and their meanings, for use when producing plane sheets.

Table 1 · Ring and Frame
- TruSky 13: ecliptic constellation and degrees into the arc — the sidereal reading
- TruSky 27: galactic constellation and degrees into the arc
- F/F/V arc: supergalactic ring arc and degrees into it
- Kind: whether that F/F/V arc is a structure arc or a void arc
- Tropical, Sidereal, Draconic (mean and true), Galactic l, SGL, Lattice, Ecl lat / Gal lat / SGB
- H, Shell, GQ — house, Lyric-Distance Shell, Gauquelin sector

Table 2 · Terrain Position
- Octant, Depth, Seat, Slab (E/G/S residence), Cell, Shell

Table 3 · Seven-Attribute Depth Stake
- 1 Ecliptic (invariant), 2 Galactic (invariant), 3 Supergalactic (invariant)
- 4 Terrain (F/F/V classification), 5 Lattice (station·offset·unit), 6 Family · H (harmonic), 7 Alignment
- Chamber (chamber named by the cell)
